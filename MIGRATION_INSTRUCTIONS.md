# Инструкция по применению миграции для системы объявлений

## Изменения

Внесены следующие изменения в модель `Announcement`:

1. **Поле `created_at` переименовано в `published_date`**
   - Теперь это поле не устанавливается автоматически
   - Администратор должен вручную указывать дату публикации при создании объявления

2. **Поле `created_by` переименовано в `author`**
   - Автор автоматически устанавливается как пользователь, создавший объявление
   - Поле доступно только для чтения в админке

3. **Сортировка изменена**
   - Объявления теперь сортируются по дате публикации (а не по дате создания)
   - На фронтенде отображается дата публикации

## Применение миграции

### Шаг 1: Активируйте виртуальное окружение

```cmd
activate.ps1
```

или

```cmd
venv\Scripts\activate
```

### Шаг 2: Примените миграцию

```cmd
python manage.py migrate announcements
```

### Шаг 3: Проверьте изменения

После применения миграции:
- Все существующие объявления сохранят свои даты (старое поле `created_at` станет `published_date`)
- Все существующие авторы сохранятся (старое поле `created_by` станет `author`)
- Индекс базы данных будет обновлен для оптимизации запросов по дате публикации

### Шаг 4: Запустите тесты (опционально)

```cmd
python manage.py test announcements
```

## Использование в админке

После применения миграции при создании нового объявления:

1. Заполните заголовки и содержимое на обоих языках
2. **Обязательно укажите дату публикации** в поле "Дата публикации"
3. Поле "Автор" заполнится автоматически вашим именем пользователя

## Примечания

- Миграция безопасна и не приведет к потере данных
- Все существующие объявления останутся доступными
- Изменения обратно совместимы с существующими шаблонами
